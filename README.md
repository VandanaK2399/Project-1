# Ecommerce Order Fulfilment Analysis

## Project Overview
This project analyzes the **end-to-end ecommerce order fulfilment process**, from order creation to final delivery. The objective is to evaluate delivery efficiency, agent and vendor performance, and identify demand patterns.

## Dataset Description
The dataset covers the complete order lifecycle and includes:
- **Agent details** (agent name, vehicle type)
- **Order details** (order number, type, status, vendor)
- **Transaction details** (order amount, delivery fee, service fee, payment option)
- **Delivery details** (distance, time, pickup and drop-off timestamps)

## Key Metrics
- Creation to Accept Time  
- Accept to Arrive Time  
- Creation to Deliver Time  
- Delivery distance and duration  
- Order volume by day and time  

## Project Scope
- Determine delivery efficiency  
- Analyze vendor efficiency  
- Evaluate agent and vehicle performance  
- Identify peak and off-peak delivery periods  

## Key Insights
- Highest order volume on **Fridays**
- Agent performance driven by **creation-to-accept, accept-to-arrive, and creation-to-deliver times**
- Vendor performance based on **number of orders**
- **Peak hours:** 12 PM – 9 PM  
- **Low demand day:** Wednesday
- Customer segmentation identifies **frequent** and **bulk purchasers**
- **Wallet payments preferred by 99% of customers**

## Recommendations
- Reward frequent and bulk purchasers with loyalty benefits
- Promote offers during off-peak days
- Incentivize agents for efficient delivery performance

## Tools Used
- Data Analysis and Visualization (Power BI)
